# RAG Resume Screening App

## Overview

The **RAG Resume Screening App** is an AI-powered recruitment assistant that leverages **Retrieval-Augmented Generation (RAG)** and **Large Language Models (LLMs)** to intelligently evaluate resumes against job descriptions.

Instead of relying solely on keyword matching, the application performs semantic understanding of both resumes and job requirements using embeddings and vector search. It retrieves the most relevant information from resumes and generates accurate candidate evaluations using an LLM.

This project demonstrates practical implementation of **Generative AI**, **Prompt Engineering**, **Vector Databases**, and **Retrieval-Augmented Generation (RAG)** for enterprise recruitment workflows.

---

## Features

* Upload resumes in PDF format
* Input custom job descriptions
* Semantic resume retrieval using vector embeddings
* AI-powered candidate evaluation
* Skill matching and gap analysis
* Resume ranking based on job relevance
* Explainable hiring recommendations
* Natural language insights generated by an LLM

## Architecture

1. Upload Resume (PDF)
2. Extract Resume Text
3. Split into Chunks
4. Generate Embeddings
5. Store in Vector Database
6. Retrieve Relevant Context
7. Send Retrieved Context + Job Description to GPT
8. Generate Candidate Evaluation

## Installation

```bash
git clone https://github.com/yourusername/rag-resume-screening.git

cd rag-resume-screening

pip install -r requirements.txt
```

Create a `.env` file:

```env
OPENAI_API_KEY=your_api_key
```

Run the application:

```bash
streamlit run app.py
```

or

```bash
uvicorn main:app --reload
```
